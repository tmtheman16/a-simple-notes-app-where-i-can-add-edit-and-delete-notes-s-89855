# NoteMate

A minimalist notes app for capturing thoughts and ideas directly in the browser.

## Features
- Add Notes
- Edit Notes
- Delete Notes
- Search Notes
- Organize Notes
- Sync Notes
- Offline Access
- Export Notes

## Usage
1. Open the `index.html` file in your browser.
2. Use the navigation bar to switch between screens.
3. Add, edit, and delete notes as needed.

## Development
This project is a static web app with no build step. Simply open the `index.html` file in your browser to run it.
